# 《斗破苍穹：焰帝归途》设计文档（总提示词）

> 本文档根据与用户 64 个问题的问答整理，是整个项目的“总提示词”。之后每一版开发都以此为准；如有改动，会在文末的「变更记录」里写明。

## 0. 一句话概述
俯视角 2D 精致像素风的**动作肉鸽**（手感参考《哈迪斯》）。以萧炎为主角，覆盖原著全本剧情（乌坦城 → 魂天帝），**核心玩法是异火吞噬融合**，外加**海量斗技自由搭配**。有局外势力建设、炼药、同伴、羁绊，玩梗多。

## 1. 基础规格
| 项目 | 决定 |
|---|---|
| 引擎 | Godot 4.4（GDScript），导出为 Windows x64 exe，打包成 zip，发布到 GitHub Release |
| 视角 | 2D 俯视 / 斜 45° |
| 美术 | 精致像素风，角色 48–64px；立绘也用高精度像素 |
| 色调/UI | 每章不同色调；UI 主题随章节/地图变化 |
| 操作 | 键鼠（WASD + 鼠标瞄准）+ 手柄 |
| 语言 | 简体中文 |
| 电脑 | Windows、1080p、普通配置（60fps 为目标） |
| 基调 | 忠实热血，梗和彩蛋多（成就、道具描述、死亡台词、加载小贴士） |
| 难度 | 档位（凡人/斗者/斗宗/斗帝）+「天劫」加难词条 |
| 存档 | 自动存档，每个房间/节点存一次，退出后可以继续 |

## 2. 结构与节奏
- **章节式推进**，每章 1 小时左右，每章有大 Boss。
- **地图**：三种结构都用，按章节交替：
  1. 分支路线地图（杀戮尖塔式）：战斗 / 精英 / 坊市 / 炼药房 / 奇遇 / 修炼 / 拍卖 / Boss；
  2. 房间制（哈迪斯式），门上显示奖励；
  3. 小型开放区域（后续版本加）。
- **死亡**（三者结合，由玩家选择）：用还魂丹等复活道具原地复活；否则回基地，可以从本局起点重开，也可以直接从已通关的章节开始。

## 3. 境界系统（章节限定上限 + 局内突破）
斗之气(1–9段) → 斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 半圣 → 斗圣 → 斗帝。
- 每章限定境界上限；局内通过击杀、吞噬、修炼节点、丹药积累“斗气”来突破。
- 突破：全屏演出，角色外观变化（斗气铠甲、双翼、光环），技能槽增加。
- 高境界（斗宗/斗圣/斗帝）需要**渡劫**（小 Boss 战）。

## 4. 战斗系统
### 4.1 技能槽（8 主动槽为终极形态 + 随境界解锁）
普攻 / 身法 / 斗技×3 / 大招×2 / 同伴；被动：功法 1、异火 N、法宝 N。槽位数量随境界增加（斗者 4 格 → 斗帝全开）。
- **每个技能都可以设成 手动 / 自动释放**。
- **身法由装备决定**：三千雷动 → 闪现；紫云翼/斗气化翼 → 飞起越过障碍；默认 → 翻滚冲刺。
### 4.2 斗技品阶与数量
- 品阶：黄 / 玄 / 地 / 天阶，每阶分低、中、高，用颜色区分。
- **技能进化线**：同一斗技升阶会改变形态；特定技能组合会触发**融合**，得到新技能（例如 八极崩 + 焰分噬浪尺 → 焰崩）。
- 数量目标：v1 约 80+ 个技能/被动，后续逐版扩到数百个；再加上品阶和进化，组合数达到上千。
### 4.3 萧炎
- 普攻风格多样可选：玄重尺（重击、吸扯、震地）/ 拳掌 / 火焰远程 / 骨灵冷火爪 / 异火飞刃 等，每种风格的普攻连段都不同。
- 大招：原著大招全部收录，需要逐个获得。**佛怒火莲固定为招牌**，会随融合的异火数量进化；另外有一个可更换的大招槽（帝印决、三千焱炎火、焚诀化身……）。
- 药老：剧情向导 + 附身大招（“老师，借我力量！”）+ 后期可玩。
### 4.4 异火（核心）
- 异火榜 23 种全收录，分批加入。
- 吞噬：需要消耗丹药/材料 + 完成“体内异火反噬”耐力小游戏，失败扣血。
- 融合：每种组合都有不同的效果，佛怒火莲的颜色和效果随之变化。
### 4.5 打击感
顿帧、震屏、击飞、伤害数字、华丽特效，全部可以在设置里调强弱/开关。

## 5. 角色
- 主要角色**各自有完全独立的机制**；朋友靠剧情解锁，敌人靠击败解锁，隐藏角色靠挑战解锁。
- 同伴：可带 1–2 名 AI 同伴，能下指令（跟随/进攻/守护/集火），有合击技。
- 羁绊：好感度 + 专属剧情 + 好感解锁合击技。
- 皮肤：原著/动画多套造型 + 随境界变化的外观。

v1 可玩角色（每人独立机制）：
| 角色 | 独立机制 |
|---|---|
| 萧炎 | 异火吞噬/融合，多种武器风格，佛怒火莲进化 |
| 萧薰儿 | 金帝焚天炎，“古族血脉”觉醒槽，满了进入金色觉醒形态 |
| 美杜莎（彩鳞） | 人形/蛇形切换，毒层 + 石化凝视 |
| 云韵 | 风之剑舞，连击计数，风压领域 |
| 小医仙 | 厄难毒体：自己流血变强，毒雾领域，毒层引爆 |
后续版本：紫妍、纳兰嫣然、药老、萧战、林动（彩蛋）、海波东、韩枫、魂天帝、古元……

## 6. 敌人与 Boss
- 按区域 + 按势力混合设计：魔兽山脉魔兽、狼头佣兵团、塔戈尔沙漠蛇人、云岚宗弟子、魂殿、魂族……
- **所有剧情 Boss 和精英怪都还原，都有多阶段**；风格是弹幕 + 动作混合，阶段转换时有对白演出和变身。
- 另有异火本体/守护兽 Boss 和隐藏 Boss。

## 7. 经济与获取
- 货币：金币（局内）、魔核、药材（炼药）、斗气结晶（局外）、贡献点（势力）、异火火种。
- 技能获取：清完房间三选一、掉落、坊市购买、拍卖、任务奖励、藏经阁永久解锁。
- 奇遇事件：原著名场面（拍卖会、洞府、捡到戒指、魔兽幼崽……）+ 赌石 + 拍卖竞价小游戏。

## 8. 炼药（三种形式融合）
- 局内简单合成：药材 + 丹方 → 丹药。
- 炼丹小游戏：控火候，品质越高效果越好，有丹雷。
- 局外炼药：炼出的丹药可以带进下一局。

## 9. 局外
- 势力随剧情进化：萧家 → 磐门 → 炎盟 → 星陨阁 → 萧族。
- 建筑：炼药房、藏经阁、修炼室（天赋）、天火塔（异火培养）、炼器坊、招待所（同伴）、图鉴馆、挑战塔。
- 功法层级：焚决。另有图鉴、成就。
- 模式：主线、无尽（天火塔无限层）、每日挑战、Boss 车轮战。

## 10. 剧情
- 全本 8–10 章：
  - 序章：炎帝演示关（满级体验 → 倒叙回少年时期）
  - 第 1 章：乌坦城 / 魔兽山脉（斗之力三段、药老苏醒、纳兰退婚、三十年河东）
  - 第 2 章：加玛帝国 / 塔戈尔沙漠 / 云岚宗（美杜莎、青莲地心火、云岚宗之战）
  - 第 3 章：迦南学院 / 天焚炼气塔（陨落心炎）
  - 第 4 章：黑角域 / 丹会
  - 第 5 章：中州 / 花宗 / 丹塔
  - 第 6 章：魂殿 / 救药老
  - 第 7 章：天墓 / 古族 / 萧族
  - 第 8 章：魂族 / 魂天帝（终章）
- 呈现：像素对话 + 像素立绘 + 关键剧情 CG。
- 配音：只给招式喝名和关键台词配音（AI 语音，先试听选声音）。

## 11. 美术与音频来源
- 优先用免费/可商用素材；原著专属内容找不到时用 AI 生成，再由程序处理成统一的像素风格（去背景、降采样、调色板量化、描边）。质量必须严格把关，不能有“贴图感”。
- 特效：以程序化粒子 + Shader 为主（火焰、异火、斗气、雷电），保证华丽且风格统一。
- 音效：程序合成 + 免费素材；配乐：国风五声调式。

## 12. 设置
按键重绑、音量分轨（总/音乐/音效/语音）、特效强度、震屏开关、顿帧开关、伤害数字、全屏/窗口、帧率上限。
