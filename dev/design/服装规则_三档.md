# 服装规则（三档）— 用户 2026-09-27 确认

1. **普通敌人 / Boss / 配角：一人一套。** 画游戏里遇到他时，漫画那一话穿的衣服。
2. **可玩主角（萧炎、薰儿、美杜莎、云韵、小医仙）：每章一套**（剧情换装，自动切换，带换装小过场）。每套都要骨骼绑定。
   - 如果漫画中该阶段衣服没变，就沿用上一套。
3. **特殊场合服装（婚纱、宴会装等）：只做剧情插图 / 立绘**，不做战斗用的骨骼绑定角色图。
