# 斗破苍穹：焰帝归途

基于《斗破苍穹》的像素动作 Roguelike（Godot 4.4）。同人作品，仅供个人娱乐。

下载：见 Releases，解压后运行 exe。

## v0.1.0 内容
- 序章（炎帝演示关）+ 第一章 乌坦城·魔兽山脉（分支地图）+ 第二章 塔戈尔沙漠·云岚宗（房间门）
- 可玩角色：萧炎 / 萧薰儿 / 美杜莎 / 云韵 / 小医仙（各有独特机制）
- 80+ 斗技、12 大招、身法/功法/法宝、斗技品阶进化与融合、词条
- 异火榜 23 种异火与吞噬小游戏；炼丹小游戏与丹雷
- 局外基地：炼药房、藏经阁、修炼室、天火塔（无尽模式）、炼器坊、招待所、图鉴馆、挑战塔
- 4 档难度 + 12 条天劫、完整设置与改键、自动存档

## 仓库结构
- 游戏工程：根目录（project.godot / scripts / scenes / assets）
- `dev/`：开发资料（设计文档 design/、AI原图 art_src/、生成与测试工具 tools/），导出时排除
